# Calculator 🧮
A mobile-first watercolor calculator workbench. No backend, no ads, localStorage persistence, snow animation.

## Included
- Basic calculator with %, ±, memory, decimal and history
- Scientific functions
- Length and weight conversion
- Automatic local saving
- Responsive mobile UI
- Watercolor-inspired palette #4ba7ca + #ffb6c1
- Exact calculator emoji logo: 🧮

- Bundled font: TC Antiquated Sans (`fonts/TCAntiquatedSans-Regular.otf`)
